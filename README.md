# WordRules — Ultra Master 2.0.0

Consolidação editorial das versões A e B do guia de regras para sistemas de IA. O projeto separa núcleo normativo, módulos especializados, avaliação, proveniência e governança. Não é reprodução integral dos repositórios de origem e não garante comportamento de qualquer modelo.

## Estado de verificação

A suíte e a auditoria de comportamento permanecem honestamente separadas: os casos foram consolidados e auditados estaticamente, mas não representam testes externos executados contra modelos. A contagem estrutural recomputada nesta edição é 5.406 entradas internas não vazias nos 13 contêineres do acervo disponível; o valor histórico de 5.410 é mantido como discrepância documentada porque usou uma definição/pacote diferente.

## Escopo público

O repositório publica sínteses e documentação de proveniência. Não inclui ZIPs brutos, `.crdownload`, caches, binários, prompts potencialmente adversariais ou cópias integrais de terceiros.
